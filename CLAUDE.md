# Project Instructions for AI Agents

This file provides instructions and context for AI coding agents working on this project.

## Work Tracking

Linear is the durable source of truth for planning and implementation work.
Use GitHub issues for repository-facing intake, then link accepted work to the
correct Linear issue, project, and initiative. Internal work belongs in the
Palmetto Interactive workspace; client delivery belongs in the Palmetto
Interactive Clients workspace.

Give every initiative a one-sentence outcome description and list or link the
GitHub repositories it governs. Assign each implementation issue to the
correct project and associate that project with its governing initiative.

Keep Linear ownership, status, priority, and relationships current. Link pull
requests to the relevant Linear issue. Never put secrets, vulnerability
details, customer data, or private incident notes in public GitHub issues or
ordinary Linear issues.
